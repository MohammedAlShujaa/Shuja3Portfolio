Wireframe Documentation

Personal Portfolio Website

Mohammed Al-Shujaa Information Engineering, UNTAG Surabaya

The following low-fidelity wireframes show the layout of each of the four pages before the visual design and coding stage. They define the position of every required element (profile, headline, buttons, skills, project cards, filters, and the contact form) and were used as the reference for building the final site.

Notation: dashed boxes are content placeholders, solid outlines are titles or buttons, and rounded shapes marked as pills are the category filter controls. All four pages share the same top navigation bar and footer.

Navigation

The navigation bar is identical on all four pages. It stays fixed at the top of the screen, highlights the current page, and collapses into a single menu button on screens narrower than 768 pixels so that every page remains reachable on a phone. This satisfies the requirement for a menu that reaches every page.
